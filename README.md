# BLUE JELLY AQUARIUM — Developer Preview

既存の勉強タイマー、チケット、環境音、青い文字クラゲを残し、右上に **DEV MODE** を追加。

- 8種類の海洋生物を3D粒子でプレビュー（全種類／個別）
- サイズ・発光・泳ぐ速さを調整
- 開発者モードは勉強時間・チケット・生物コレクションを変更しません
- 通常の水族館コレクション表示は従来の記号表示のままです（開発用3Dプレビューを追加した段階）

## 公開
ZIPを展開し `index.html`, `style.css`, `main.js`, `app.js`, `dev.js` をリポジトリ直下にアップロードしてコミット。GitHub Pagesが更新されたら強制再読み込み。

Three.jsはCDN経由のためオンライン接続が必要です。
